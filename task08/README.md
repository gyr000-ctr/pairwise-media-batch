# task08

## 题面（可直接粘贴）

固定步长累加器。约束：按步长切分、不足一步返回 0、最大步数保护；必须支持时间缩放与暂停，以及最大追赶（spiral-of-death 保护：单帧最多追赶 N 步且不得丢时间）；100 万次推进不超过 200 ms 且浮点累积误差 ≤1e-9；负时间、非法步长、非法缩放要给出可区分的错误；并发推进同一实例安全。验收：cd task08 && python -m pytest tests -q -k step。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 10 万次推进耗时
- 并发
- 非有限 dt
- 浮点累积误差
- 极大步长
