# pairwise-hdr

## 题面（可直接粘贴）

HDR 色调映射。约束：非负、0 映射为 0、单调、结果不超过 1；必须同时实现全局 Reinhard 与局部（梯度域或分块）映射，局部与全局结果差异有界且不产生光晕；100 万像素不超过 400 ms、峰值内存 ≤原图 1.5 倍；并发安全；负值与非有限输入要报错。验收：python -m pytest tests -q -k tonemap。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 大图耗时
- 并发
- 非有限输入
- 极大值
- 多通道
